# Рулетка подарков

Офлайн-приложение для Android: гость нажимает кнопку, рулетка вращается и показывает случайный подарок вместе с его изображением.

## Возможности

- 8 подарков и их изображения встроены в APK — интернет и сервер не нужны;
- вращение 15 секунд с плавной остановкой;
- полноэкранное поздравление с крупным emoji подарка и конфетти;
- встроенная праздничная мелодия с русским поздравлением (9 секунд);
- кнопки возврата к рулетке, отключения и повторного воспроизведения звука;
- легко изменить список подарков в `app/src/main/java/ruletka/app/MainActivity.java`;
- портретный интерфейс для телефона.

## Сборка

Откройте проект в Android Studio и нажмите **Run** или **Build > Build APK(s)**. Для GitHub достаточно загрузить весь репозиторий, кроме `.gradle/` и `build/`.

## Как добавить свои изображения

В текущей версии изображения подарков — emoji в TextView. Они отображаются системным шрифтом Android. Для брендированных картинок добавьте PNG/WebP в `app/src/main/res/drawable` и используйте ImageView на экранах рулетки и поздравления.

## Поздравление и музыка

После остановки открывается `WinnerActivity`. Аудиофайл `app/src/main/res/raw/celebration.mp3` входит в APK, поэтому музыка и голос работают без интернета и без установки голосового движка на телефоне. Текст: «Поздравляем! Рулетка выбрала твой подарок! Спасибо за участие!».

Мелодия создана скриптом `tools/generate_fanfare.py`, голос синтезирован системным русским голосом Milena на macOS. При закрытии экрана или уходе из приложения аудио останавливается. Громкость регулируется кнопками телефона; приложение не изменяет установленную пользователем громкость.

### Набор подарков

Большой подарок, сертификат, кофе, скидка 20%, шоппер, брелок, конфеты и приз «Спасибо за участие!».
