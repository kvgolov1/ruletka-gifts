# Рулетка подарков

Офлайн-приложение для Android: гость нажимает кнопку, рулетка вращается и показывает случайный подарок вместе с его изображением.

## Возможности

- подарки и картинки встроены в APK — интернет и сервер не нужны;
- плавная анимация вращения;
- легко изменить список подарков в `app/src/main/java/ruletka/app/MainActivity.java`;
- портретный интерфейс для телефона.

## Сборка

Откройте проект в Android Studio и нажмите **Run** или **Build > Build APK(s)**. Для GitHub достаточно загрузить весь репозиторий, кроме `.gradle/` и `build/`.

## Как добавить свои изображения

В текущей версии изображения подарков — встроенные emoji, поэтому APK полностью автономен. Для брендированных картинок добавьте PNG/WebP в `app/src/main/res/drawable` и замените `ImageView` в `spin()` на `setImageResource(R.drawable.<имя_файла>)`.
